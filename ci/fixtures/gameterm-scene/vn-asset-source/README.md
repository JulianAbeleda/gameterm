# GameTerm VN Asset Intake Test Fixtures

These files are repo-owned PNG placeholder assets for deterministic Scene Mode
asset-intake tests. They are copied from GameTerm-owned bundled Scene Mode test
sprites, not from itch.io, Ren'Py, DDLC, or any third-party visual novel asset
pack.

The directory names mirror catalog source IDs so the intake helper can verify
catalog policy and source mapping without vendoring third-party art.
